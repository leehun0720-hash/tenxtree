# 한 그루의 나무가 하나의 데이터가 될 때

**트리헌드레드 × 텐에이아이 — 그린 AX 파트너십 랜딩페이지**

🌐 **[leehun0720-hash.github.io/tenxtree](https://leehun0720-hash.github.io/tenxtree/)**

나무를 심는 것은 사람이 하고, 기록하고 증명하는 일은 AI가 합니다.
사단법인 리본디어스의 트리헌드레드 캠페인과 ㈜텐에이아이의 AI 기술을 잇는 공동사업 소개 페이지입니다.

**타겟** — 특정 업종이나 기관 유형으로 한정하지 않습니다. **AI 전환(AX)과 ESG가 필요한 조직**이면 기업·공공기관·지자체·학교·재단 어디든 대상이며, 시민 참여 경로도 함께 둡니다.

---

## 구성

```
index.html              전체 페이지 (단일 파일, 빌드 불필요)
assets/earth.mp4        영상 밴드 배경 · 1600×900 · 16초 무한 루프 · 5.4MB
assets/earth-poster.jpg 영상 포스터 (모션 최소화 설정 시 대체 표시)
PLAN.md                 기획안 (v2 현행 / v1 기록)
```

브라우저에서 `index.html`을 열면 바로 동작합니다. 별도 빌드나 서버가 필요 없습니다.
`assets/` 폴더는 `index.html`과 같은 위치에 있어야 영상이 재생됩니다.

## 디자인 시스템

treehundred.com 실측값을 승계했습니다.

| 토큰 | 값 | 비고 |
|---|---|---|
| `--forest` | `#09381F` | 트리헌드레드 사이트 지배색 |
| `--paper` | `#F8F7F4` | 트리헌드레드 /about 배경색 |
| `--ink` | `#212121` | 트리헌드레드 본문색 |
| `--gold` | `#8C6425` | 라벨 악센트 (페이퍼 위 4.9:1) |
| `--ink-mute` | `#616159` | 보조 텍스트 (4.5:1 이상) |

**폰트** — 본문 Pretendard, 라벨·숫자 Montserrat (둘 다 트리헌드레드 자산), 헤드라인 Nanum Myeongjo.

## 접근성 · 품질

브라우저 실측 기준입니다.

- 390 / 768 / 1440px 가로 스크롤 없음
- 명암비 자동 감사 (배경 합성 계산) 실패 0건 — WCAG AA
- 터치 타겟 40px 미만 0개
- 콘솔 에러 0건
- `prefers-reduced-motion` 대응 — 애니메이션·영상 정지, 포스터 대체
- 시맨틱 마크업, skip link, 키보드 내비게이션, JSON-LD 구조화 데이터

## 설정이 필요한 항목

| 항목 | 위치 | 현재 상태 |
|---|---|---|
| 문의 폼 수신처 | `index.html` 스크립트 상단 `FORM_ENDPOINT` | 비어 있음 → 메일 클라이언트로 대체 전송 |
| 사진 | 전체 `<img>` | Unsplash 임시 이미지. 실제 활동 사진으로 교체 필요 |
| OG 이미지 | `<head>` | `og:image` 미설정 (1200×630 필요) |
| 도메인 | `<link rel="canonical">` | GitHub Pages 주소. 자체 도메인 확정 시 교체 |
| 로고 | 헤더·푸터 SVG | 자체 제작 심볼. 공식 로고 확보 시 교체 |
